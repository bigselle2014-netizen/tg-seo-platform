# TZ-MINI-APP-2026 — Telegram Mini App для управления постами
> Основано на: исследовании конкурентов (Combot/TGStat/Telemetr/SMMplanner) + Telegram Mini Apps API docs + @tma.js пакеты
> Дата: 2026-05-14
> Гарантия: реализация строго по этому ТЗ, проверяется на устройстве перед сдачей

---

## ВЫВОД ИЗ ИССЛЕДОВАНИЯ

Ни один конкурент (Combot, TGStat, Telemetr, SMMplanner, ControllerBot) не имеет Mini App для управления постами канала. **Мы первые в нише.**

Единственный близкий пример — SmartMod (модерация групп): бот как точка входа → кнопка открывает Mini App → dashboard с действиями. Именно эту архитектуру берём за основу.

---

## КОНЦЕПЦИЯ

**Бот** = уведомления + онбординг (добавить канал)
**Mini App** = всё управление постами, статистика, настройки

Пользователь никогда не управляет постами через чат-бота. Бот только сообщает: "SEO-статья готова" → кнопка → Mini App.

## ЭКРАНЫ

### Экран 0: Загрузка (< 300ms)
- Скелетон мгновенно (CSS shimmer на `--tg-theme-secondary-bg-color`)
- `WebApp.ready()` вызывается ДО загрузки данных — Telegram прячет свой лоадер
- Имя пользователя из `initDataUnsafe.user.first_name` — показывается сразу, без запроса к серверу

### Экран 1: Список каналов
```
Post SEO · Привет, Вагиз

📢 @seorezult          ✅ активен    →
📢 @vagchannel         ⏳ ждёт бота  →

[+ Добавить канал]
```
- Если каналов 0 → пустой стейт: иллюстрация + "Добавьте первый канал"
- Тап на канал → Экран 2
- Кнопка "Добавить" → бот в Telegram (deeplink) для онбординга

### Экран 2: Канал — статистика + действия
```
← @seorezult

📊 В поиске: 12 постов
👁 Просмотров/30д: 340
👆 Переходов: 23
Автопубликация: 🟢 ВКЛ

[📄 Публикации (47 ждут)]
[🟢 Автопубликация: ВКЛ]     ← toggle
[⚙️ Настройки]
```
- BackButton (нативная кнопка Telegram) → Экран 1
- Toggle автопубликации — PATCH запрос, мгновенный UI update

### Экран 3: Список постов (ГЛАВНЫЙ ЭКРАН)
```
← @seorezult · Публикации

✅ В поиске: 12  ⚡ Ждут: 47  ⚫ Короткие: 8

🔍 [Поиск по тексту]

☐  Почему SEO не может стоить...   14 янв
☐  Кейс - Омоложение               12 янв
☑  Анализ конкурентов              10 янв  ← выбран
☐  А вот и ссылки...                9 янв
☐  Аудит безопасности...            8 янв
...виртуальный список, 1000+ постов...

──── sticky header когда выбрано ─────
  ☑ Выбрано: 1    [Выбрать все] [Снять]
──────────────────────────────────────

[    ⚡ Продвинуть (1)    ]   ← MainButton
```

**Поведение:**
- Список виртуализирован (`react-window`) — работает при 1000+ постах
- Тап на пост = toggle ☐/☑ + `HapticFeedback.selectionChanged()`
- MainButton скрыт когда выбор = 0, показывает "Продвинуть (N)" при N > 0
- Sticky header с "Выбрано N / Выбрать все / Снять" появляется при первом выборе
- Фильтры: Все / Ждут / В поиске / Короткие (табы под поиском)
- `WebApp.disableVerticalSwipes()` — чтобы список не схлопывался

### Экран 4: Настройки канала
```
← @seorezult · Настройки

Автопубликация
[🟢 ВКЛ]

Задержка публикации
[Без] [10м] [30м] [1ч] [2ч]

[🗑 Удалить канал]
```

### Онбординг-состояние: "Канал добавлен, загружаем"
Когда пользователь только добавил канал и Mini App открывается впервые:
```
@seorezult подключён! 🎉

⏳ Загружаем историю постов...
████████░░░░░░░  57%

Это займёт 1-2 минуты.
Можете закрыть — пришлём уведомление.
```
- Прогресс-бар с реальным polling каждые 3 сек (`/api/channels/{id}/scrape-status`)
- MainButton: "Закрыть" → закрывает Mini App

## ТЕХНИЧЕСКИЙ СТЕК

| Компонент | Решение | Почему |
|---|---|---|
| Размещение | `/mini` роут в существующем Next.js 15 | Не нужен отдельный деплой |
| SDK | `@tma.js/sdk-react` | Активно поддерживается (релиз 22 дня назад) |
| UI компоненты | `@telegram-apps/telegram-ui` | Нативный вид Telegram (TON Foundation) |
| Валидация auth | `@tma.js/init-data-node` | Официальный пакет |
| Виртуальный список | `react-window` | Обязательно для 1000+ постов |
| Стили | Tailwind + TG CSS переменные | Автоматический dark/light mode |

## АУТЕНТИФИКАЦИЯ (без паролей)

```
Пользователь открывает Mini App
→ Telegram передаёт initData (подписано HMAC-SHA256)
→ /api/auth/telegram проверяет подпись через BOT_TOKEN
→ Возвращает JWT (7 дней)
→ JWT в localStorage, все запросы с Bearer заголовком
```

**Нет логина. Нет паролей. Нет email.** Идентификация только через Telegram.

## ОТКРЫТИЕ MINI APP

### 1. MenuButton (всегда доступна в любом чате с ботом)
Уже настроен в коде:
```typescript
bot.api.setChatMenuButton({
  menu_button: { type: "web_app", text: "Открыть панель", web_app: { url: `${SITE_URL}/mini` } }
})
```

### 2. Из уведомления бота
```
✅ SEO-статья опубликована!

📝 Анализ конкурентов пример...

[🚀 Открыть панель]   ← web_app кнопка → /mini?startapp=channel_UUID
```

### 3. startapp параметр
Когда Mini App открывается через `?startapp=channel_UUID` — автоматически переходит на Экран 2 нужного канала.

## ПРОИЗВОДИТЕЛЬНОСТЬ

| Метрика | Цель |
|---|---|
| JS бандл | < 150KB gzipped |
| Time to First Paint | < 800ms |
| Список 1000 постов | 60fps scroll |
| Skeleton до данных | < 300ms |

**Что делаем:**
- `WebApp.ready()` вызываем сразу — не ждём данных
- Skeleton shimmer на `--tg-theme-secondary-bg-color` (dark/light автоматом)
- `react-window` для всех списков > 50 элементов
- Code splitting по роутам (`lazy()`)
- `disableVerticalSwipes()` на экране списка постов
- Только `transform`/`opacity` анимации (не `top`/`left`/`width`)
- Нет `backdrop-filter` (убивает Android WebView)

## ИЗМЕНЕНИЯ В БОТЕ

1. Кнопки "Открыть статью" / "К публикациям" в уведомлениях → заменить на одну:
   `[🚀 Открыть в панели]` — web_app кнопка с `?startapp=channel_UUID`

2. Кнопка "Открыть панель" в `screenChannel` → web_app кнопка (уже URL, просто обновить на `/mini`)

3. Удалить `screenPosts` из бота — он переехал в Mini App
