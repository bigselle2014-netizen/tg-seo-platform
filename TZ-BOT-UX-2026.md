## ЗАДАЧА 1 — Создать страницу /how-to-add-bot [КРИТИЧНО]

**Проблема:** строка 639 route.ts — кнопка "📖 Инструкция" ведёт на `${SITE_URL}/how-to-add-bot`. Страница не существует → 404.

**Решение:** создать `frontend/src/app/how-to-add-bot/page.tsx`

**Содержимое страницы:**
- H1: "Как добавить бота в канал"
- 4 шага с иконками и скриншотами (или иллюстрациями):
  1. Откройте канал в Telegram → три точки → Управление каналом
  2. Администраторы → Добавить администратора
  3. Найдите @tg_buster_bot
  4. Выдайте права: "Публикация сообщений" ✅ → Сохранить
- После шагов: кнопка "Я добавил бота — перейти в бота" (ссылка на t.me/tg_buster_bot)
- Стиль: соответствует дизайн-системе (светлая тема, CSS-токены)

## ЗАДАЧА 2 — Отправить результат SEO-аудита пользователю [КРИТИЧНО]

**Проблема:** строка 344 route.ts — "Результат пришлю через минуту" — обещание которое никогда не выполняется. `analyze_channel` запускается fire-and-forget, результат никуда не идёт.

**Решение:** создать endpoint `POST /api/notify/audit-done` в frontend.

**Файл:** `frontend/src/app/api/notify/audit-done/route.ts`

```typescript
// Принимает от worker: { channel_id, topics, keywords, indexable_count, focus_score }
// Проверяет X-Worker-Secret
// Находит channel → user → telegramId
// Отправляет Telegram сообщение с результатами аудита
```

**Текст сообщения боту:**
```
📊 SEO-аудит канала @{username} готов!

🎯 Главные темы:
• {topic1}
• {topic2}  
• {topic3}

🔑 Ключевые слова: {kw1}, {kw2}, {kw3}, {kw4}, {kw5}

📈 Фокус канала: {focus_score*10}/10
📄 Готово к индексации: {indexable_count} постов

[кнопка: 📄 Посмотреть публикации → ch:posts:{channelId}:p:1:all]
[кнопка: 🚀 Открыть панель → loginUrl]
```

**Изменения в worker/content_pipeline.py** — в `analyze_channel()` после получения результата:
```python
# Notify frontend about audit result
frontend_url = os.getenv("FRONTEND_URL", "http://frontend:3000")
worker_secret = os.getenv("WORKER_SECRET", "")
async with httpx.AsyncClient(timeout=5) as http:
    await http.post(
        f"{frontend_url}/api/notify/audit-done",
        json={"channel_id": channel_id, **result},
        headers={"X-Worker-Secret": worker_secret}
    )
```

## ЗАДАЧА 3 — Упростить инструкцию по добавлению бота [UX]

**Проблема:** строки 629-641 — стена текста с 4 шагами. Нетехническому пользователю сложно.

**Текущий текст (плохо):**
```
✅ Канал @{rawUsername} теперь зарегистрирован!

📌 Теперь добавьте бота @{botUsername} как администратора в канал:

1. Откройте настройки канала
2. Администраторы → Добавить администратора
3. Найдите @{botUsername}
4. Выдайте права: публикация сообщений ✅

После добавления я пришлю вам ссылку для входа в панель управления.
```

**Новый текст (хорошо):**
```
✅ Канал @{rawUsername} зарегистрирован!

Теперь добавьте @{botUsername} как администратора канала.
Нужно только одно право — публикация сообщений.

Как только добавите — я сразу пришлю доступ в панель.
```

**Кнопки:**
- "📖 Пошаговая инструкция" → `${SITE_URL}/how-to-add-bot`
- "✅ Уже добавил — проверить" → `ch:check_activation:{rawUsername}`

## ЗАДАЧА 4 — Улучшить сообщение после активации [UX]

**Проблема:** после активации пользователь получает "Бот добавлен + SEO-аудит запущен" и кнопку "Открыть панель". Непонятно что делать дальше в боте.

**Новый текст:**
```
✅ Бот добавлен в @{channelUsername}!

📊 Запускаю SEO-аудит — результат пришлю через минуту.

Что дальше:
• Импортируйте историю постов
• Включите автопубликацию
• Первые результаты в поиске — через 2-7 дней
```

**Кнопки:**
- "📄 Мои публикации" → `ch:posts:{channelId}:p:1:all`
- "🚀 Открыть панель" → `loginUrl`
- "🏠 Главное меню" → `menu:main`
