БАЗА ЗНАНИЙ: Post SEO (post-seo.seo-rezult.ru)

=== НАЗВАНИЕ И СУТЬ ===
Название сервиса: Post SEO
URL: https://post-seo.seo-rezult.ru
Суть: SaaS-платформа, которая автоматически превращает посты из Telegram и MAX-каналов в SEO-статьи, индексируемые в Яндексе и Google. Владелец канала подключает бота, и каждый новый пост становится полноценной веб-страницей с заголовком, мета-описанием, LSI-оптимизацией и Schema.org разметкой.

=== КАК РАБОТАЕТ (ПАЙПЛАЙН) ===
1. Владелец добавляет бота @tg_buster_bot (Telegram) или @id701745447807_3_bot (MAX) как администратора канала
2. При новом посте бот автоматически получает текст
3. AI pipeline: извлекает поисковый запрос → XMLStock SERP ТОП-20 Яндекс → TF-IDF LSI анализ → DeepSeek генерирует SEO-статью 800-1200 слов → FAQ секция
4. Статья публикуется на post-seo.seo-rezult.ru/channel_username/slug
5. IndexNow пингует Яндекс и Bing — индексация за 2-72 часа
6. Google Search Console и Яндекс Вебмастер отслеживают позиции

=== КОНКУРЕНТНОЕ ПРЕИМУЩЕСТВО ===
TGPages (главный конкурент): генерирует короткое описание поста (100-200 слов). Только Telegram.
Post SEO: генерирует полноценную SEO-статью 800-1200 слов с LSI-оптимизацией, SERP-анализом конкурентов, FAQ секцией, Schema.org BlogPosting. Поддерживает Telegram И MAX мессенджер.

=== ЧТО ПОЛУЧАЕТ ВЛАДЕЛЕЦ КАНАЛА ===
- Органический трафик из поиска без дополнительных усилий
- Каждый пост = новая точка входа в канал из Яндекса/Google
- Старые посты работают годами, привлекая новых подписчиков
- Позиции в поиске видны в личном кабинете (Google + Яндекс)
- Уведомление в Telegram когда статья попала в поиск

=== ТЕХНОЛОГИЯ ===
- AI: DeepSeek V4 Flash + toolselfizal.ru (7-этапный пайплайн)
- SERP анализ: XMLStock Яндекс ТОП-20
- LSI: TF-IDF алгоритм (Title: слова в ≥35% документов, Description: 15-35%)
- Индексация: IndexNow (Яндекс + Bing), ручной пинг Google через GSC
- Позиции: Google Search Console API + Яндекс Вебмастер API (ежедневный cron)
- Мессенджеры: Telegram Bot API + MAX Bot API

=== ЦЕЛЕВАЯ АУДИТОРИЯ ===
- Владельцы Telegram-каналов (новости, эксперты, бизнес)
- Владельцы MAX-каналов (аудитория РФ, 55 млн DAU)
- Маркетологи и SMM-специалисты
- Агентства с несколькими каналами

=== СРОКИ РЕЗУЛЬТАТА ===
- Индексация Яндекс/Bing: 2-72 часа (через IndexNow)
- Первые позиции в Яндексе: 2-4 недели
- Устойчивый трафик: 2-4 месяца
- Google: медленнее, 1-3 месяца до первых позиций
